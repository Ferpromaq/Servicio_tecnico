# Ferpromaq · Servicio Técnico

Nueva versión independiente de la aplicación de servicio técnico.

## Requisitos
- Node.js 20+
- Variables `NEXT_PUBLIC_SUPABASE_URL` y `NEXT_PUBLIC_SUPABASE_ANON_KEY`, además de las variables privadas usadas por las rutas del servidor.

## Desarrollo
```bash
npm install
npm run dev
```

Configura los secretos en `.env.local`. No subas credenciales al repositorio.
